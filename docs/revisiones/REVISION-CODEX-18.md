## Hallazgos

1. **[P2] `start` exige que Higgsfield responda en cada arranque y falla incluso si ya estaba configurado.** `src/hf_studio/launcher.py:55` llama siempre a `_setup`, que siempre llama a `_check_credentials` (`src/hf_studio/cli.py:114-127`). Si Higgsfield está caído, falla DNS o no hay red, `HiggsfieldClient.check_credentials` deja propagar `httpx.TransportError` (`src/hf_studio/higgsfield.py:116-125`): el comando termina con traceback antes de levantar siquiera la API y la biblioteca local. Los README (`README.md:79-81`, `README.es.md:70-72`) y la ayuda de `start` presentan la validación como parte de la primera puesta en marcha. Validar la clave al configurarla y tratar un fallo transitorio de red en arranques posteriores sin impedir el servicio; conservar el rechazo de una clave inválida cuando se compruebe.

2. **[P2] El comando impreso para Windows no está protegido frente a metacaracteres de `cmd.exe`.** `src/hf_studio/setup.py:161-163` usa `subprocess.list2cmdline`, que prepara argumentos para el parser de un proceso Windows, pero no escapa la sintaxis de la consola. Con el repo en `C:\Work&Stuff\hf-studio`, la salida para `connect codex --print` o para una CLI ausente contiene `--directory C:\Work&Stuff\hf-studio`: `&` divide el comando. También son problemáticos `^` y la expansión de `%...%`. La prueba Windows (`tests/test_setup.py:104-109`) solo usa una ruta con espacios. El registro directo pasa una lista de argumentos y no tiene este fallo; el problema afecta precisamente a la ruta que la documentación pide copiar y pegar. Generar una línea válida para la consola indicada y probar rutas con metacaracteres.

3. **[P2] El proceso puede anunciar la UI aunque `next dev` haya fallado.** `src/hf_studio/launcher.py:65-74` lanza `pnpm dev`, imprime la URL y entra en `uvicorn.run` sin comprobar si la UI sigue viva. Por ejemplo, si el puerto 3000 está ocupado, Next sale y la API sigue en primer plano hasta Ctrl+C; `start` no señala que la mitad de la puesta en marcha falló. `_stop` además retorna inmediatamente si `pnpm` ya salió (`:28-34`), sin intentar cerrar posibles hijos de su grupo. Comprobar el arranque de la UI y propagar su fallo; al cerrar, limpiar el grupo aunque el proceso padre ya haya terminado.

4. **[P2] El inicio rápido de ambos README falla en Windows PowerShell 5.1.** `README.md:71-75` y `README.es.md:62-66` presentan `git clone ... && cd hf-studio` seguido de `.\dev` como instrucciones también para PowerShell. PowerShell 5.1, incluido habitualmente con Windows, no admite `&&`, así que el usuario no llega al comando de arranque. Separar `git clone` y `cd` en líneas compatibles con cmd y PowerShell, y mostrar los comandos de cada sistema en bloques claros.

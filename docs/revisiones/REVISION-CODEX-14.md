# Revisión adversarial del árbol sin commit sobre `da4c3a8`

Fecha: 2026-09-28. Alcance: las 25 herramientas MCP y sus rutas REST, los README bilingües, `LICENSE`, `SECURITY.md`, los metadatos del paquete y `tests/test_mcp_tools.py`. No se hicieron llamadas de generación a Higgsfield ni a ElevenLabs.

## Hallazgos

1. **[P1] `list_sounds` declara solo lectura, pero puede escribir en la base de datos.** `src/hf_studio/mcp_server.py:400-415` fija `readOnlyHint=True` y llama a `GET /v1/sounds`. Esa ruta ejecuta `backfill_sounds` antes de devolver los resultados (`src/hf_studio/api.py:1136-1146`); si hay trabajos de audio completados sin registro en la sonoteca, crea `Sound` y hace `commit` (`src/hf_studio/sounds.py:306-318`). Es precisamente el caso que la pista promete excluir. Quitar el backfill de la lectura o marcar la herramienta como escritura y probar el caso con un trabajo pendiente de registrar.

2. **[P1] El README y la política de seguridad prometen una barrera de gasto que la API REST no tiene.** `README.md:15,23-24,39,133-141` y `SECURITY.md:14-15` dicen que nadie genera sin ver el precio, que la API exige cotización y que un agente debe obtener el OK del usuario. `POST /v1/generations` llama directamente a `create_generation` sin `quote_id` ni confirmación (`src/hf_studio/api.py:426-448`; `src/hf_studio/service.py:61-71,126-136`); lotes y presets también aceptan `dry_run=False` sin cotización previa (`src/hf_studio/api.py:480-550,692-725`). El propio ejemplo REST de `README.md:191-198` omite la cotización. El MCP sí exige su `quote_id`, pero tampoco puede comprobar que una persona haya visto el precio o haya dado su OK: eso queda en las instrucciones del agente (`src/hf_studio/mcp_server.py:34-40,573-600`). Precisar el alcance real de la garantía en ambos README y en `SECURITY.md`, o imponerla en la API si esa es la promesa del producto.

3. **[P2] `estimate_cost` y `recommend_models` ocultan contacto con Higgsfield en `openWorldHint`.** Ambas declaran `openWorldHint=False` (`src/hf_studio/mcp_server.py:134-146,524-534`), pero `/v1/estimate` llama a `hf.estimate` (`src/hf_studio/api.py:343-363`) y `/v1/recommend` cotiza modelos mediante esa misma llamada (`src/hf_studio/recommend.py:140-141`; `src/hf_studio/pricing.py:200-222`). `hf.estimate` envía un POST a Higgsfield (`src/hf_studio/higgsfield.py:137-143`). No genera ni gasta créditos de generación, pero sí sale del entorno local. Marcar ambas como `openWorldHint=True`.

4. **[P2] `estimate_cost` tampoco es estrictamente de solo lectura.** Cada llamada crea un `quote_id` distinto y modifica `_quotes` en el proceso MCP (`src/hf_studio/mcp_server.py:140-146,558-570`), mientras anuncia `readOnlyHint=True`. El efecto es temporal y no modifica la base de datos, por lo que es menos grave que el backfill de `list_sounds`, pero sí crea una capacidad canjeable durante 15 minutos. Revisar esa pista según el contrato que se quiera ofrecer a los clientes MCP; si se conserva como solo lectura, documentar expresamente que la emisión de cotizaciones es una excepción interna.

5. **[P2] Los tests nuevos comprueban presencia de pistas y despacho, pero dejan sin verificar las dos pistas más delicadas y el contrato de cotización.** `tests/test_mcp_tools.py:49-60` exige cuatro booleanos, pero compara los valores esperados solo para `readOnlyHint` y `destructiveHint`; los `openWorldHint=False` incorrectos pasan. El mock de `tests/test_mcp_tools.py:72-87` responde `{"ok": true}` a las rutas de generación y a cotizaciones que deberían traer `voice_quote` o `audio_quote`. `tests/test_mcp_tools.py:151-175` solo comprueba que se llamó a la ruta, no que la cotización de la API viajó en el POST. `generate`, `generate_batch` y `run_preset` aparecen en `TOOLS`, pero no tienen pruebas de su ejecución con y sin cotización válida. Añadir expectativas para los cuatro valores y casos MCP con `_call` simulado que rechacen un `quote_id` inválido, comprueben el token enviado a la API y cubran el backfill de `list_sounds`. Las pruebas actuales de rutas, nombres, WSL y rechazo de descargas incompletas sí ejercitan comportamiento útil.

6. **[P3] «Jobs that survive restarts» necesita acotar su alcance.** `README.md:25-27` sugiere que todos los trabajos sobreviven al reinicio, pero el arranque marca como `failed/interrupted` los cambios de voz y trabajos de audio activos (`src/hf_studio/api.py:163-181`). Su historial persiste, no la ejecución. Aclararlo en esa frase para evitar que quien instala HF Studio espere reanudación de audio.
